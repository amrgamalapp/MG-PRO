# منصة المهندس محمد جمال عوض - المكتب الفني المساحي

منصة ويب عربية (RTL) متخصصة في كورسات المكتب الفني: إعداد الداتا، حساب الكميات، المستخلصات، وشيتات الإكسيل الجاهزة.

## الملفات

| الملف | الوصف |
|-------|-------|
| `index.html` | الموقع الرئيسي: الدخول برقم الهاتف، مشغل الفيديوهات المحمي، الكورسات، الشيتات، الأسئلة الشائعة |
| `admin.html` | لوحة تحكم المهندس: تفعيل/إلغاء تفعيل/حذف الطلاب + إحصائيات + تصدير CSV |
| `firebase-config.js` | إعدادات Firebase المشتركة بين الصفحتين |

## التشغيل السريع

1. افتح `index.html` في المتصفح مباشرة (أضل على سيرفر بسيط زي Live Server لو عايز تفعيل Firebase الكامل).
2. لوحة التحكم: `admin.html`
   - اسم المستخدم: `eng_mohamed`
   - كلمة المرور: `admin1234` ← **غيّرها فوراً بعد أول دخول**

## إعداد الفيديوهات الحقيقية

في `index.html` عدّل مصفوفة `VIDEO_CONFIG` وضع معرّف كل فيديو يوتيوب بدل `dQw4w9WgXcQ` (القيمة الحالية مجرد placeholder - مأخوذة من الجزء بعد `watch?v=` في رابط الفيديو):

```js
const VIDEO_CONFIG = [
    { id: 'معرّف_الفيديو_1', title: '...', fullTitle: '...', desc: '...', duration: '18:45' },
    // ...
];
```

## إعداد Firebase Rules

قواعد مقترحة لـ Realtime Database (قاعدة البيانات الحالية تعمل بهذا النمط):

```json
{
  "rules": {
    "students": {
      ".read": true,
      ".write": true
    }
  }
}
```

> ملاحظة أمنية: النظام الحالي يعتمد على رقم الهاتف فقط. للإنتاج الحقيقي استخدم Firebase Authentication أو Cloud Functions، ولا تعرض مفتاح API في ملفات عامة.

## تحسينات تمت في هذه النسخة

**عام:**
- إصلاح امتداد الملفات (كان `.html.html`)
- فصل إعدادات Firebase في ملف مشترك `firebase-config.js`
- إشعارات Toast بديلة لـ `alert` في كل العمليات
- تحسينات SEO (وصف، كلمات مفتاحية، لون الثيم)

**الموقع (index.html):**
- قائمة موبايل (هامبرغر) + زر خروج للمشتركين
- قسم إحصائيات بعدادات متحركة عند التمرير
- حركات ظهور ناعمة (Scroll Reveal) للأقسام
- مشغل فيديو: قائمة تشغيل تُبنى تلقائياً من الإعدادات + أزرار الدرس السابق/التالي + مؤشر التقدم + فيديو عبر `youtube-nocookie` (خصوصية أعلى)
- تسجيل دخول بحفظ الجلسة (localStorage) مع إعادة تحقق من Firebase عند فتح الصفحة
- تحقق من صحة رقم الهاتف المصري (010/011/012/015) قبل الإرسال
- تحميلات فعلية: شيت CSV للمستخلصات، ملف LSP لأوتوكاد، قالب PNEZD - بتتولّد فوراً من المتصفح
- بحث فوري داخل قسم الشيتات
- قسم أسئلة شائعة (FAQ) بأكورديون
- فوتر كامل بروابط سريعة + زر واتساب عائم نابض
- إضافة تفاصيل محتويات كل دورة ومدتها
- تحسينات الموبايل: منع السكريول الأفقي، أبعاد ثابتة لصور المهندس، زر واتساب بالأيقونة فقط على الشاشات الصغيرة، نافذة الدخول قابلة للسكريول، أزرار الدروس تتكيف مع العرض، وإيقاف تأثير hover على الشاشات اللمسية

**لوحة التحكم (admin.html):**
- جلسة لوحة التحكم محفوظة (sessionStorage) تظل بعد تحديث الصفحة
- إزالة تعبئة كلمة المرور تلقائياً
- بطاقات إحصائيات حية (إجمالي/مفعل/معلق)
- بحث فوري في جدول الطلاب
- حذف طالب مع تأكيد
- تصدير قائمة الطلاب CSV
- عرض المحافظة وتاريخ التسجيل في الجدول
- مؤشر حالة الاتصال بـ Firebase (.info/connected)
- ترتيب الطلاب الأحدث أولاً + تنظيف المدخلات ضد XSS

## ملاحظات

- الأرقام والإحصائيات في قسم الإحصائيات (500+ طالب...) قيم تجريبية - عدّلها من `data-target` في HTML.
- مدة الدروس في `VIDEO_CONFIG` قيم تجريبية - حدّثها عند رفع الفيديوهات الحقيقية.
