MG Engineering Academy — مشروع الموقع الكامل (نسخة أولية)
======================================================
المكونات:
- واجهة طلاب عربية متجاوبة مع بحث وتصفية حسب التخصص.
- صفحات تفاصيل للكورسات مع رابط فيديو وملف مرفق.
- لوحة مدير محمية بجلسة تسجيل دخول.
- إضافة وتعديل وحذف المحتوى، ونشر/إخفاء المحتوى.
- رفع ملفات PDF وExcel وDWG وZIP وصور وفيديوهات وغيرها من الامتدادات المسموحة.
- إعدادات Flask وVercel وملف requirements.txt.

التشغيل المحلي:
1) Python 3.10+.
2) pip install -r requirements.txt
3) ضبط متغيرات البيئة:
   ADMIN_USERNAME = اسم المدير
   ADMIN_PASSWORD = كلمة مرور قوية
   FLASK_SECRET_KEY = سلسلة عشوائية طويلة وفريدة
4) python app.py
5) افتح http://127.0.0.1:5000
   لوحة المدير: http://127.0.0.1:5000/admin/login

مهم جدًا قبل الاستخدام الحقيقي على Vercel:
هذه الحزمة نموذج وظيفي أولي، وليست إعدادًا إنتاجيًا كاملًا. Vercel بيئة Serverless، لذا ملفات JSON والرفع داخل مجلد المشروع لا تعتبر تخزينًا دائمًا. يلزم استبدال تخزين JSON بقاعدة بيانات دائمة (مثل Supabase/Postgres) ونقل المرفقات إلى تخزين دائم (مثل Supabase Storage أو Vercel Blob) قبل رفع كورسات فعلية. كذلك يفضل تخزين ملفات الكورسات المدفوعة بشكل خاص وتوليد روابط مؤقتة، وإضافة CSRF وحماية معدل محاولات الدخول ومراجعة الأمان قبل الاستخدام العام. لا تضع كلمات المرور في GitHub، واضبط القيم في Environment Variables فقط.
فيديوهات YouTube: أدخل رابط الفيديو. بعض روابط watch تحتاج تحويلًا إلى رابط embed كي تعمل داخل إطار المشاهدة؛ زر فتح الفيديو الخارجي متوفر دائمًا.
